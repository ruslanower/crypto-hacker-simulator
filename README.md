# 💻 Crypto Hacker Simulator (Симулятор Криптохакера)

Мобільний симулятор-клікер (Idle / Incremental Game) у жанрі кіберпанк / Web3 безпека, розроблений на кросплатформенному рушії **Flutter** для **Android** (перший реліз) та **iOS**.

---

## 🚀 Ігрові системи та механіки

1. **Термінал та ручний майнінг (Clicker Core Loop):**
   - Блискавичний ручний тап: підбір хешів, злам відкритих RPC-портів, перехоплення приватних ключів.
   - Жива консоль виконання шеллкодів із реальними прецедентами та командами.
   - Спливаючі цифри прибутку, тактильний відгук (Haptic Feedback) та кіберпанк-неон анімації.

2. **Залізо (Hardware Upgrades):**
   - Прогрес від дешевої мишки з макросами та механічної клавіатури до серверних CPU, ферм 8x RTX 5090, промислових контейнерів Antminer S21 та квантових симуляторів Shor-алгоритму.
   - Експоненційне масштабування вартості за формулою: $Cost_n = BaseCost \times 1.15^n$.

3. **Софт та ботнети (Passive CPS Income):**
   - Спам-боти у Telegram, Clipper-трояни підміни буфера, прихований Cryptojacking ботнет Monero (RandomX), снайпери MEV-сендвіч атак та Zero-Day брокери.

4. **Цільові кібероперації (Real-world Heists):**
   - Реальні історичні прецеденти:
     - *Discord Web3 Drainer* (масовий фішинг).
     - *Wintermute $160M* (дефект ентропії Profanity).
     - *Euler Finance $197M* (математична вразливість ліквідації eToken/dToken).
     - *Ronin Bridge $620M* (компрометація 5 із 9 валідаторів Lazarus).
     - *Bybit Historic $1.5B Heist* (лютий 2025 р. — сліпе підписання Safe інтерфейсу).

5. **Менеджмент ризику: Поліція та шкала загрози (FBI Heat Meter):**
   - Усі пограбування генерують "брудну" криптовалюту та підвищують шкалу загрози (`Heat`).
   - Якщо `Heat` досягає 100% — настає **Рейд кіберполіції**, конфіскуючи до 85% невідмитих коштів!
   - Механіка відмивання через **Tornado Cash** (-12% комісії, перетворення брудної крипти на чистий долар і зниження загрози).
   - Екстрена зміна VPN/MAC та знищення одноразових телефонів (Burner phones).

6. **Престиж: «Операція Чистий Аркуш» (Panama Escape):**
   - Коли прогрес сповільнюється, гравець спалює старі паспорти та тікає в офшорну зону.
   - Нараховується **Darknet Credibility**, кожен бал якої дає перманентний бонус **+5% до абсолютно всіх доходів назавжди**.

7. **Симуляція крипторинку та бірж:**
   - Котирування в реальному часі для PoW-монет (BTC, XMR, KAS, DOGE, RVN) та PoS/Staking активів (ETH, SOL, PEPE).
   - Рейтинг надійності топ-10 бірж (Binance, Coinbase, Bybit, OKX, Kraken, Hyperliquid DEX).

8. **Офлайн-нарахування та автозбереження:**
   - Повне збереження прогресу через `SharedPreferences`.
   - Нарахування до 8 годин офлайн-прибутку ботнетів при повторному відкритті гри.

## 🛠️ Структура проєкту

```
lib/
├── main.dart                      # Точка входу, Material 3 Dark Hacker Theme, навігація
├── models/
│   ├── upgrade_item.dart          # Модель заліза та софту (Hardware / Software / Security)
│   ├── hack_target.dart           # Модель цільових рейдів з кулдаунами та шансом успіху
│   ├── crypto_market.dart         # Симуляція монет (PoW/PoS) та цінових коливань
│   └── achievement.dart           # Система ігрових титулів та досягнень
├── providers/
│   └── game_state.dart            # Серце симулятора (таймери, кліки, Heat, престиж, сейви)
├── ui/
│   ├── theme/
│   │   └── hacker_theme.dart      # Неонові зелений (#00FF66), бірюзовий (#00F0FF), обсидіан (#070B11)
│   ├── widgets/
│   │   └── stat_header.dart       # Хедер із балансами, CPS, хешрейтом та шкалою FBI Heat
│   └── screens/
│       ├── terminal_screen.dart   # Головний клікер-екран із логами та літаючими цифрами
│       ├── hardware_shop_screen.dart # Магазин ПК, мишок, відеокарт та ASIC
│       ├── exploits_screen.dart   # Магазин пасивних ботнетів та експлойтів
│       ├── targets_screen.dart    # Цільові рейди та відмивання Tornado Cash
│       └── market_screen.dart     # Ринок монет, топ бірж та Престиж (Втеча в Панаму)
└── utils/
    └── number_formatter.dart      # Форматування чисел (K, M, B, T, Qa, Qi) та хешрейту
```

## 📱 Запуск та збірка на Android

Для запуску на емуляторі чи підключеному смартфоні:
```bash
flutter run
```

Для збірки релізного APK:
```bash
flutter build apk --release
```
Файл APK з'явиться у:
`build/app/outputs/flutter-apk/app-release.apk`
