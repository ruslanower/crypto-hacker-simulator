# 💻 Crypto Hacker Simulator (Cipher Vault Odyssey)

Мобільний та веб-симулятор криптохакера (Idle / Incremental Game) у жанрі кіберпанк / Web3 безпека.
Проєкт містить повноцінний сучасний **Web-клієнт** (створений та покращений у Lovable з TanStack Start, React 19, Tailwind CSS, shadcn/ui) та нативний мобільний додаток **Flutter** (`flutter_app/`) для **Android** та **iOS**.

---

## 🎮 Нові можливості та геймплей (Lovable Update)

1. **Термінал та майнінг (Core Loop):**
   - Ручний підбір хешів, злам RPC-портів, перехоплення приватних ключів.
   - Жива консоль виконання шеллкодів із реальними прецедентами та звуковими ефектами (Cyber Synth Audio FX).
   - Літаючі цифри прибутку, візуальний відгук та кіберпанк-неон анімації.

2. **Залізо (Hardware Upgrades) & Darknet:**
   - Поступовий апгрейд від дешевої мишки з макросами до 8x RTX 5090, промислових контейнерів Antminer S21 та квантових симуляторів.
   - Експоненційне масштабування вартості та збалансована крива прогресу.

3. **Софт, ботнети та експлойти (Passive CPS):**
   - Ботнети Monero (RandomX), Clipper-трояни підміни буфера, снайпери MEV-сендвіч атак та Zero-Day брокери.

4. **Цільові кібероперації (Real-world Heists):**
   - Реальні історичні прецеденти:
     - *Discord Web3 Drainer* (масовий фішинг).
     - *Wintermute $160M* (дефект ентропії Profanity).
     - *Euler Finance $197M* (математична вразливість eToken/dToken).
     - *Ronin Bridge $620M* (компрометація 5 із 9 валідаторів Lazarus).
     - *Bybit Historic $1.5B Heist* (сліпе підписання Safe інтерфейсу).

5. **Менеджмент ризику: Поліція та шкала загрози (FBI Heat Meter):**
   - Пограбування генерують "брудну" криптовалюту та підвищують шкалу `Heat`.
   - При досягненні 100% — рейд кіберполіції з конфіскацією до 85% невідмитих коштів.
   - Механіка відмивання через **Tornado Cash** (-12% комісії, очищення коштів та зниження загрози).

6. **Симуляція крипторинку та бірж:**
   - Котирування в реальному часі для PoW та PoS монет (BTC, ETH, SOL, XMR, KAS, DOGE, PEPE).
   - Рейтинг бірж (Binance, Bybit, Coinbase, OKX, Kraken, Hyperliquid DEX).

7. **Престиж: «Операція Чистий Аркуш» (Panama Escape):**
   - Втеча в офшор із конвертацією у Darknet Credibility (+5% перманентного бонусу до всіх доходів за бал).

## 🌐 Запуск Web-версії (React / TanStack Start / Vite)

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка продакшн версії
npm run build
npm run preview
```

---

## 📱 Запуск та збірка мобільної версії (Flutter / Android & iOS)

Код мобільного застосунку знаходиться в директорії `flutter_app/`:

```bash
cd flutter_app

# Запуск на підключеному смартфоні чи емуляторі
flutter run

# Збірка релізного APK для Android
flutter build apk --release
```
Готовий APK: `flutter_app/build/app/outputs/flutter-apk/app-release.apk`
